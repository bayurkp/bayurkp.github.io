## Overview

A modern task management application designed for teams to collaborate effectively.

## Features

- Drag-and-drop Kanban boards
- Real-time updates via WebSockets
- Team workspaces and permissions
- Due date reminders
- Activity logging

## Tech Stack

Built with Next.js 14, TypeScript, Prisma ORM, and PostgreSQL.
