An elegant weather application providing accurate forecasts and beautiful visualizations.

## Features

- Current weather conditions
- 7-day forecast
- Hourly predictions
- Interactive weather maps
- Severe weather alerts

## Tech Stack

Built with Vue.js 3, Tailwind CSS, and OpenWeather API.
