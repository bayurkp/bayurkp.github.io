## Overview

Moodyan is a decentralized journaling application focused on data privacy and mental health. Built during the ICP Indonesia Hackathon where we won 1st place.

## Features

- Blockchain-based authentication using Internet Identity
- AI-powered mood analysis with Llama 3.2:8B
- Fully decentralized data storage
- Privacy-first approach
