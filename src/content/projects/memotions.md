## Overview

Memotions is a journaling app with machine learning and gamification features, addressing mental health challenges. Capstone project for Bangkit Academy.

## Features

- AI-powered mood tracking
- Gamification elements for engagement
- Firebase Cloud Messaging notifications
- Deployed on Google Cloud Run
