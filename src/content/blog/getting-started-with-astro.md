## Introduction

Astro is a modern static site generator that ships zero JavaScript by default.

## Why Astro?

- **Performance**: HTML-first architecture
- **Flexibility**: Works with React, Vue, Svelte
- **Content**: Built-in content collections

## Getting Started

```bash
npm create astro@latest
```

Follow the prompts and you'll have a new project ready to go.
